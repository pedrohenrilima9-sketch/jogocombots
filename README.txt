# Leilão de Futebol com Mata-Mata (Bots sem Lances)

## Modificações:
1. **Bots sem lances no leilão**: Os bots entram na sala apenas para preencher o torneio de mata-mata até 16 equipes. Eles **não dão lances** e não disputam os jogadores nas rodadas de leilão (o leilão é feito exclusivamente entre os jogadores humanos).
2. **Leilão ágil (5 segundos)**.
